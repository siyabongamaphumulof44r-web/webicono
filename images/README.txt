Product photos
==============
Save each photo in this folder using the file name below (JPG, roughly square, plain background).
Then open ../data.js and change  useImageFiles: false  to  useImageFiles: true.
Any product without a file keeps its illustrated placeholder, so you can add photos gradually.
Only use photos you have the right to publish, for example from your HP partner portal.
